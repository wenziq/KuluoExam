# 推箱子｜技术策划笔试作品

**完整关卡体验 + 运行时关卡工坊** · Unity 6000.6.3f1 · 简体中文 · 离线运行

我把这道题理解为：既要让玩家顺畅地完成一套关卡，也要让策划能够独立制作、验证和交付下一套关卡。因此，项目围绕一条实际工作流程展开：

**制作地图 → 编排顺序 → 检查与分析 → 试玩调整 → 加入可玩关卡集 → 导出交付**

## 一分钟了解作品

- **一套完整的游戏流程**：六关教学内容，包含选关、顺序解锁、暂停、撤销、重开、单关结算与整套通关，正式进度本地保存。
- **一套可直接使用的制作工具**：在游戏内绘制地图、调整尺寸、复制与排序关卡、保存草稿、试玩和交换关卡包，无需修改代码或手填 JSON。
- **一套帮助设计判断的分析工具**：检查遗漏项、判断有解性、批量分析、观察参考解指标、逐推回放与接管，以及复检修改后的旧路线。

## 我围绕哪些策划痛点做设计

| 策划遇到的问题 | 设计与实现 | 为什么这样做 |
|---|---|---|
| 画完地图，还要找程序接入游戏 | 运行时工坊统一处理地图、关卡顺序和可玩版本；列表顺序直接决定连玩顺序 | 让策划自己完成内容制作与交付，减少逐关配置和沟通往返 |
| 调整一个想法的试错成本高 | 连续绘制、对象分层选择、复制、拖动排序、统一撤销/重做；分别提供“试玩当前”和“从头试玩” | 既能快速验证局部解法，也能连续检查整套关卡的教学与节奏 |
| 地图不完整，或不知道卡在哪里 | 结构问题可定位；提供静态死格提示、有解性分析、参考解回放及接管 | 从“报错”进一步走到“看到原因、找到位置、动手验证” |
| 能通关，却不清楚解法是否符合设计意图 | 展示推动、总步数、纯行走、换箱和把箱子推离目标五项指标；换箱与离开目标可定位到具体步骤 | 让策划观察绕行负担、多箱配合和临时让位，再结合试玩作判断 |
| 改图或误操作影响正式内容 | 草稿、可玩版本、试玩和正式成绩分开；提供离开保护、恢复快照、保存备份与失败回滚 | 允许安心试错；只有明确“加入/更新可玩关卡集”才改变正式内容 |

## 几个关键取舍

**1. “产品级”首先落实在可用、可信、可恢复。** 先保证完整流程和数据安全，再打磨交互：分析结果居中保留、文件导入导出使用系统选择窗口、大地图可缩放和平移。高频操作直接可见，低频管理收进文字菜单；延长搜索只在普通搜索达到限制时出现，降低理解成本。

**2. 分析辅助设计，难度仍由策划判断。** 区分“有解”“已证明无解”“暂未判定”，超时不能当作无解；只有完成证明才标注“最少推动”。五项指标来自当前参考解，不用搜索耗时或未经试玩校准的综合分代替玩家体验。

**3. 用共同规则连接工具与游戏。** 正式游玩、工坊试玩和参考解验证共用规则。求解采用以推动为单位的 A* 搜索，配合静态死格检查；后台分析可取消，布局改变后旧报告会过期。加入可玩关卡集前逐关验证，整包成功才更新，避免半套内容进入游戏。

## 建议这样体验

1. **先玩六关**：从“第一次推动”到“不能拉回、学会绕行、临时让位、多箱协调、综合挑战”，观察如何在经典规则内逐步引入思考，而不依靠增加机关。
2. **再改一关**：进入“关卡工坊 → 从示例复制”，修改地图，检查遗漏项并分析；查看参考解，或直接“试玩当前”，返回后继续编辑。
3. **最后走一次交付流程**：调整关卡顺序并“从头试玩”，选择“关卡集操作 → 加入可玩关卡集”，回到“关卡集”正式游玩；随后返回工坊，通过“关卡集操作 → 导出可玩包”交付。

内置六关也通过同一套工坊控件完成制作、分析、试玩和导出；这条流程有自动化验证，工具能够生产游戏实际使用的内容。

## 启动与工程说明

1. 在 Unity Hub 中安装 **Unity 6000.6.3f1**。
2. 下载或克隆本仓库。在 Unity Hub 的「项目」页选择「添加 → 从磁盘添加项目」，选择包含 `Assets`、`Packages`、`ProjectSettings` 的 **KuluoExam 根目录**。
3. 用上述版本打开工程，等待依赖解析和资源导入完成。首次导入需要联网获取依赖。
4. 在 Project 窗口打开 `Assets/Project/Scenes/Boot.unity`，点击顶部 **Play**，切换到 **Game** 窗口，即可游玩或进入关卡工坊。

- **操作**：方向键 / WASD 移动，Z 撤销，R 重开，Esc 暂停；工坊也提供可见按钮及悬停说明。
- **工程交付**：本次提交 Unity 工程文件。
- **范围与验证**：地图支持 4×4～20×20，每套最多 30 关。已开展规则、求解、文件故障与界面回归测试，以及 Mac 图形六关验证；Windows 构建通过，目标机图形/DPI/性能及陌生用户无指导验收仍待补。复杂地图可能暂未判定。
